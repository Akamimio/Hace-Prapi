# Hace Prapi
A lightweight English-language offline penalty-kick PWA.

## Play
Tap or drag inside the goal to aim and release to shoot. The goalkeeper moves left and right. Score as many goals as possible in 10 shots. Keyboard: arrow keys to aim, Space to shoot.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload **all files in this folder to the repository root** (not the ZIP itself).
3. Open Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Wait for the HTTPS GitHub Pages link, then open it and test gameplay.
5. Paste that URL into PWABuilder.com, review the manifest and service worker checks, and generate a Windows package.
6. Complete the Microsoft Partner Center submission, including screenshots, age ratings, and privacy information. Store approval is not guaranteed.

No analytics, accounts, advertisements, or external assets. Best score is saved locally in browser storage.
